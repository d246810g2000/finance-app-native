## 8. 每月回頭審視清單

### 每月總支出

- [ ] 本月總支出相對近 3～6 個月中位數偏高還是偏低？
- [ ] 若偏高，是哪個專案／哪幾筆造成的？
- [ ] 收入扣除支出後，本月淨額是否可接受？

### 專案檢視

- [ ] 正常開銷：是否混入共同或住家費用？
- [ ] 共同開銷：大額 Shopping／3C 是否真為兩人共同？
- [ ] 住家支出：水電稅網路是否齊全、有無漏記到別的專案？
- [ ] 裝潢家具／婚禮寶典：本月是否還有大額尾款或分期？
- [ ] 房屋購置：房貸是否固定出現一筆？

### 分類與備註

- [ ] ≥$5,000 且無備註的支出，能否補上用途？
- [ ] 「晚點再記」是否已清掉？
- [ ] 子分類是否與專案一致（例如住家不該是休閒娛樂）？

### 固定 vs 彈性

- [ ] 固定支出（住家＋房貸）占月支出比例是否穩定？
- [ ] 彈性支出（正常＋共同）本月有無異常衝高？
- [ ] 資本型專案（裝潢／婚禮）是否仍在預期預算內？

## 9. 建議使用方式

1. 先看「總覽」與「每月趨勢」：哪個月份異常高？
1. 再到「專案」：高的那個月是哪個專案拉起來的？
1. 用「單筆大額」對帳：是否都認識、歸屬是否正確？
1. 每月結帳時照「審視清單」問自己 4 組問題。
1. 重跑：npm run analyze:report（CSV 更新後）
