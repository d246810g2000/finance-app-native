# 記帳調整指南（保守漸進版）

> 現有 App 總資產／帳戶餘額大致正確。**不建議批次改歷史資料**；本指南說明哪些可改、哪些別動。

## 什麼會影響總金額？

| 欄位 | 改動是否影響餘額／總資產 | 影響範圍 |
|------|-------------------------|----------|
| 金額、日期、付款／收款帳戶 | **會** | 餘額、淨資產 |
| 分類、子分類 | 通常**不會** | 圓餅圖、預算、分類統計 |
| 專案 | **不會** | 個人 vs 共用分帳、專案報表 |
| 備註、商家 | **不會** | 搜尋、商家分析 |
| 刪除／合併交易 | **會** | 一切 |

**結論：現階段只動「專案、分類、備註」相對安全；金額與帳戶欄位完全不碰。**

---

## 專案語意（你的用法）

| 專案 | 意思 |
|------|------|
| `正常開銷` | **個人**生活（含個人帳戶的利息、回饋） |
| `共同開銷` | **兩人共用**生活開銷（App 預設 50% 分帳） |
| `住家支出` | 電費、水費、瓦斯、網路、管理費、房屋稅等固定費 |
| `裝潢家具` | 裝潢、家具、大型家電（非娛樂 3C） |
| `房屋購置` | 頭期款、房貸 |
| `婚禮寶典` | 我們自己的結婚花費（非他人禮金） |
| `投資股票` | 股票、股息、券商費用等 |
| `YYMMDD-目的地` | 僅刻意追蹤的出遊才標 |

### 分類 vs 專案

- **分類**：這是什麼類型的交易（`投資收入/利息`、`餐飲食品/午餐`）
- **專案**：誰受益／哪個生活場景（個人 vs 共用）

合理組合範例：

- `投資收入/利息` + `正常開銷` ✓（銀行利息進個人帳）
- `運輸交通/高鐵` + `正常開銷` ✓（通勤，不是旅遊專案）
- `轉帳`、`代付` → 專案**留空**

## 分級：現在該改哪裡？

### 🟢 第一級 — 完全不用動

- 利息／回饋標在 `正常開銷` 或 `共同開銷`
- 高鐵／台鐵／旅行遊玩掛 `正常開銷`（通勤、輕鬆出遊）
- 轉帳帶專案標籤（影響專案分帳報表，不影響總資產）
- 支出無專案（只影響個人 vs 共用報表）
- 子分類命名不統一（`Shopping`、`燃料費` 等）
- `小伊轉帳` 獨立主分類（App 已能處理）

### 🟡 第二級 — 有空再改（一次一兩筆）

改完匯出 CSV → 匯入 App → **確認總資產沒變**。

| 優先 | 項目 | 怎麼改 | 改完檢查 |
|------|------|--------|----------|
| 1 | 明顯分類錯誤 | `汽機車/停車費` → `餐飲食品/飲料`（茶行） | 汽機車少 30、餐飲多 30 |
| 2 | 專案明顯掛錯 | `居家生活/房屋支出` → `裝潢家具` 或 `房屋購置` | 正常開銷支出減一筆 |
| 3 | 代付缺配對 | 只查對不起來的，補缺的那一邊 | 代付不計收支，總額不變 |
| 4 | `其他/跑去哪了` | 補備註或改 `雜支` | 釐清用途 |
| 5 | `理財投資/工作` | 先搞清楚是什麼再定分類 | — |

**不要做的：** 一次清空轉帳專案、一次改 36 筆公司配股專案。

### 🔵 第三級 — 新帳養成習慣

1. 支出：選 `正常開銷` 或 `共同開銷`
2. 轉帳、代付：專案留空
3. 利息：`投資收入/利息` + `正常開銷`
4. 出遊要追蹤：才掛 `YYMMDD-目的地`
5. 有發票：備註留商家名

### 🟣 第四級 — App 端（不動 CSV）

- 健檢依**分類**分離投資 vs 生活現金流
- 旅遊報表只彙總已標 `YYMMDD-目的地` 的專案
- 匯入顯示「建議檢查」清單，**預設不自動修正**
