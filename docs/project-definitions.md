# 專案定義（記帳歸屬）

依目前記帳習慣整理。App 內「共同開銷」預設 50% 分帳。

**嚴格覆核起點：** 2024-06-01（此前較鬆，分析預設不挑刺）。

| 專案 | 一句話 |
|------|--------|
| 正常開銷 | 「我」的日常支出（個人生活、個人娛樂、個人人情）。 |
| 共同開銷 | 「我與謦伊（老婆）」的共同支出，預設五五分帳（含共同日常、共同休閒、共同人情）。 |
| 住家支出 | 住家運作的固定／半固定費用：電費、網路、瓦斯、水費、稅、管理費等。 |
| 裝潢家具 | 裝潢工程費、家具與為新家購置的大型家電／設備（非娛樂用 3C）。 |
| 房屋購置 | 購屋資本支出：頭期款與房貸（本息／固定月繳）。 |
| 婚禮寶典 | 我們結婚相關的籌備與儀式花費。 |

## 正常開銷

「我」的日常支出（個人生活、個人娛樂、個人人情）。

**應記入**
- 個人餐飲（非與謦伊共同採買／外食分攤）
- 純個人交通、純個人娛樂／購物（只有自己受益）
- 孝親、純個人名義的人情（非兩人一起包的禮）
- 個人訂閱、純個人的花費
- 個人車輛相關稅費（如個人燃料稅、牌照稅）

**不應記入**
- 與謦伊共同的日常／休閒／禮金 → 共同開銷
- 家庭共用娛樂設備（如家用 Switch）→ 共同開銷
- 住家水電瓦斯網路管理費／房屋稅 → 住家支出（個人燃料稅除外）
- 裝潢／家具家電購置 → 裝潢家具
- 頭期款／房貸 → 房屋購置
- 結婚籌備花費 → 婚禮寶典

**常見分類：** 餐飲食品/*、運輸交通/*、休閒娛樂/*（個人）、人情交際/孝養父母、居家生活/日常用品（個人）、居家生活/房租（租屋期間）、居家生活/繳稅（個人燃料稅等）

## 共同開銷

「我與謦伊（老婆）」的共同支出，預設五五分帳（含共同日常、共同休閒、共同人情）。

**應記入**
- 共同外食、超市／賣場採買、共同日用品
- 兩人一起的休閒（演唱會、共同出遊相關等）
- 家庭共用娛樂（家用 Switch、遊戲片、相關配件）
- 兩人一起參加而包的禮金（他人婚禮等）
- 其他約定為共同負擔的日常花費

**不應記入**
- 純個人花費 → 正常開銷
- 住家固定費（水電瓦斯網路稅管理費）→ 住家支出
- 裝潢／家具／大型家電購置 → 裝潢家具
- 房貸／頭期 → 房屋購置
- 我們自己的結婚籌備 → 婚禮寶典

**常見分類：** 餐飲食品/*、居家生活/日常用品、休閒娛樂/*（共同／家庭）、人情交際/婚喪喜慶（共同禮金）、運輸交通（共同出行）

## 住家支出

住家運作的固定／半固定費用：電費、網路、瓦斯、水費、稅、管理費等。

**應記入**
- 電費、水費、瓦斯、網路／電信
- 管理費、清潔費
- 房屋稅、地價稅等住家相關稅（不含個人燃料稅／牌照稅）
- 車位管理／保養費（若視為住家固定支出）

**不應記入**
- 日常超市採買 → 共同開銷或正常開銷
- 裝潢工程款、家具家電購置 → 裝潢家具
- 房貸本息、頭期款 → 房屋購置
- 家庭娛樂設備（Switch 等）→ 共同開銷
- 個人燃料稅、牌照稅 → 正常開銷

**常見分類：** 居家生活/電費、居家生活/水費、居家生活/瓦斯、居家生活/網路費、居家生活/管理費、居家生活/繳稅、汽機車/汽車車位保養費

## 裝潢家具

裝潢工程費、家具與為新家購置的大型家電／設備（非娛樂用 3C）。

**應記入**
- 裝修期款／尾款、工程相關
- 家具（沙發、床墊、櫃、桌椅等）
- 為新家購置的大型家電（冷氣、洗碗機等）
- 裝潢相關耗材、安裝費

**不應記入**
- 家庭／個人娛樂 3C（Switch、遊戲片、配件）→ 共同開銷（家庭）或正常開銷（個人）
- 日常超市耗材（非裝潢用途）→ 共同開銷
- 房貸／頭期 → 房屋購置
- 水電瓦斯月費 → 住家支出

**常見分類：** 居家生活/房屋支出、居家生活/日常用品（家具家電）

## 房屋購置

購屋資本支出：頭期款與房貸（本息／固定月繳）。

**應記入**
- 頭期款
- 房貸月繳／本息
- 與購屋直接相關的大額資本支出（非裝潢）

**不應記入**
- 裝潢工程、家具家電 → 裝潢家具
- 入住後水電稅管理費 → 住家支出
- 日常開銷 → 正常／共同開銷

**常見分類：** 居家生活/房屋支出

## 婚禮寶典

我們結婚相關的籌備與儀式花費。

**應記入**
- 婚紗、攝影、喜餅、喜宴、金飾、婚禮小物／遊戲
- 與婚禮直接相關的交通、訂金／尾款

**不應記入**
- 參加別人婚禮的禮金（兩人一起）→ 共同開銷
- 參加別人婚禮的禮金（僅個人）→ 正常開銷
- 婚後日常開銷 → 正常／共同開銷
- 裝潢家具、房貸 → 對應資本專案

**常見分類：** 人情交際/婚喪喜慶、人情交際/送禮請客、運輸交通（婚禮相關）

## 快速分流

```
是購屋頭期／房貸？ → 房屋購置
是裝潢工程或家具家電？ → 裝潢家具
是水電瓦斯網路稅管理費？ → 住家支出
是我們結婚相關？ → 婚禮寶典
是我和謦伊的日常？ → 共同開銷
是我個人日常？ → 正常開銷
```
